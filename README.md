# Hotel Beachside Escape

A simple hotel booking web application developed as a second-year college project using PHP, HTML, CSS, and MySQL. The application allows users to create an account, browse hotel information, and make or manage room reservations through a straightforward booking system.

> **Note:** *This repository showcases one of my earlier web development projects. While I would approach certain implementation details differently today, I have kept the project unchanged to document my learning progress.*

## Features

### User Authentication

* User registration
* User login

### Room Booking

* Browse multiple room types
* Book rooms through an online reservation form
* Select check-in and check-out dates
* Choose a room type
* Specify the number of adults and children
* View booking details
* Edit existing bookings
* Delete bookings

### Hotel Information

* Home page with hotel overview
* About page
* Hotel features and amenities
* Photo gallery
* Contact page

### User Profile

* View personal profile information
* Display:

  * Full name
  * Username
  * Gender
  * Birthdate
  * Email address

## Tech Stack

* PHP
* HTML5
* CSS3
* MySQL
* Visual Studio Code
* XAMPP (Apache & MySQL)

## Getting Started

### Prerequisites

* Visual Studio Code
* XAMPP (Apache & MySQL)

### Installation

1. Clone the repository.

   ```bash
   git clone https://github.com/your-username/hotel-beachside-escape.git
   ```

2. Move the project folder to your XAMPP `htdocs` directory.

3. Start **Apache** and **MySQL** from the XAMPP Control Panel.

4. Open **phpMyAdmin**.

5. Create a new database.

6. Create the required tables or import the provided SQL file if available.

7. Update the database connection settings if necessary.

8. Open your browser and navigate to:

   ```text
   http://localhost/hotel-beachside-escape
   ```

## How It Works

1. Register for a new account or log in.
2. Browse the available room types and hotel information.
3. Complete the booking form by selecting:

   * Check-in date
   * Check-out date
   * Room type
   * Number of adults
   * Number of children
4. Submit the reservation.
5. View, edit, or delete your existing bookings.
6. Access your profile to view your account information.
